# Hydrocarbon-Nomenclature-Calculator-
A Python program to determine the systematic name of saturated and unsaturated hydrocarbons based on carbon and hydrogen atoms.
⚠️ Note on Code Execution and Inputs
This code was developed and tested on a simple mobile coding app. Due to the platform's limitations with taking multiple dynamic user inputs at runtime, the variable for carbon ('n') is hardcoded in the script, while the value for hydrogen ('C') is taken as a user input during execution
